# GamePulse

游戏日报与营销 Campaign 资料站。

在线访问：https://deanuwu.github.io/gamepulse-radar/

## 当前发布方式

GitHub Pages 从 `main` 分支的 `docs/` 发布。旧的整仓库上传工作流停用。

`docs/` 只包含网站页面、静态资源和版本信息。采集配置、内部状态和本机工作文件不作为站点产物发布。

首页包含近期讨论热词、视频焦点、行业情报和版本日历；品类观察进入 Campaign 档案。收藏和笔记保存在当前浏览器，不会自动跨设备同步。

日报的热词、视频焦点、行业情报与头条遵守三日信息窗口；品类观察和历史案例不受三日限制。当前内容快照来自 2026-10-27；页面打开时继续过滤过期日报内容。发布网站不自动执行每日内容采集。

独立案例报告入口： https://deanuwu.github.io/gamepulse-radar/reports.html ，共41份，可从Campaign卡片或案例报告目录进入。
