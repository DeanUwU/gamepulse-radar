> 来源：`游戏日报主站-自洽提示词.md`（Desktop）
> 这是 GamePulse 雷达站的最高治理规范，所有脚本和生成流程必须遵守。

---

## 一、全站常驻系统指令

### 热度统一定义（全站唯一口径）

定义"热度数 H"为 0–100 的标准化指数。所有板块的展示、排序、交叉比较一律使用 H。

H 的计算方法：
1. 采集原始信号（B站播放量/点赞/投币/弹幕/热门/每周必看、贴吧热议等级、热搜命中、Steam/Reddit动量）
2. 分源归一化：对每个原始信号用近 7 天滚动窗口做百分位归一化到 0–1
3. 加权合成：H = 100 × Σ(w_i × norm_i)，权重：播放量 0.30、互动率 0.25、每周必看/热门 0.20、热搜 0.15、贴吧 0.10
4. 时间窗：仅纳入近 7 天（含当日）；超期自动淘汰
5. 展示：主数值用 H，原始量作为小字附注

### 板块职能边界（不重叠、不真空）

| 板块 | 职能 |
|------|------|
| 今日讨论热词（词云）| 当日 UGC/讨论向热词，按 H 排序 |
| 内容 TOP10 | 全站综合信号 Top10，按 H 排序 |
| 内容风向与舆情（梗雷达）| TOP10 的细分拆解（鬼畜/破圈/梗百科/贴吧/风险）|
| 行业情报站（media）| 公司/产品/出海/政策新闻，近 7 天 |
| 视觉焦点 | 头条+重点游戏封面，不重复 TOP10 封面 |
| 榜单瞭望塔 | 事件&排位信号 + 外部榜单入口 |
| 版本日历·前瞻哨 | 未来节点，S/A/B 可信度标注 |
| 源覆盖报告 | 已接入/待接入/本次失败源 |

### 自洽红线

1. 任何"热度"展示只能用 H，禁止来源字面热度值充当热度
2. 同一游戏在全站各板块的 H 值、结论必须一致
3. 采集源 URL 必须是具体文章/页面地址，禁止只链主页占位
4. 近 7 天窗口，超期内容自动淘汰
5. 板块职能不重叠、不真空

## 二、每日生成/拼装流程

1. 采集：并行拉取各源，单源失败跳过
2. 深抓：GameLook 必须取到具体文章 URL
3. 算 H：按统一口径计算热度数 H（0–100）
4. 分发给板块：按职能边界路由内容
5. 板块自查：生成即自查，问题就地修复
6. 全站交叉校验：跨板块一致性
7. 处置：阻断级必须修复，优化级记入 backlog
8. 拼装：调用 rebuild_main.py 拼装主站

## 三、自洽校验（9 项检查）

### (a) 词云 H 口径
- 检查 `wordcloud.html` 中 `热度数 H=` 出现次数
- 若为 0 → 阻断

### (b) GameLook 主页占位
- 扫描 daily/wordcloud/index/主站 四个 HTML
- 检查是否有 `gamelook.com.cn` 根页链接 → 阻断

### (b2) 任意外部根页占位
- 扫描全部 5 个 HTML（含 calendar）
- 检查是否有任何无 path/query/fragment 的外部链接 → 阻断

### (c) 待接入源告警占位
- 检查 `daily.html` source 区块
- 竞核/手游那点事/DataEye 必须在占位文本中 → 优化

### (c2) 搜索链接 / 可疑详情ID
- 扫描 `search.bilibili.com` 链接 → 阻断
- 扫描无法验证的米哈游 news 数字ID 链接 → 阻断

### (c3) 日历游戏名↔域名一致性
- 使用 `GAME_DOMAIN` 映射表
- 游戏名链接到另一个游戏的官方域名 → 阻断
- 游戏名链接到本游戏官方域名或中立新闻站点 → 合规

### (c4) 信源注册表存活
- 读取 `sources_status.json`
- 任何 status ≠ 200 的源 → 优化

### (c5) 准入安检结果
- 读取 `inbox/sources_curated.json`
- 新增剔除项 → 优化

### (c7) 信源自发现
- 读取 `inbox/sources_discovered.json`
- 有建议待入库 → 优化

### (d) 跨板块 H 一致性
- 检查梗雷达 em / TOP10 meta / 视觉焦点 cap 三个槽位
- 出现原始播放量且无 H 值 → 优化

### (e) 人工策展过期
- 扫描 `data-curated` 标记
- 超过 7 天未人工刷新 → 优化

## 四、迭代升级 SOP

1. 新源接入：先写入"待接入"区，验证能取到具体 URL 后转正
2. 提示词版本化：存入 `prompts/v1.md`，修改先复制为 v(next)
3. 不自洽回灌：阻断级无法自动修复 → 告警+挂起；优化级 → backlog
4. 周期复盘：每周用最近 7 天的源覆盖报告+自洽问题清单复盘

## 五、落地的关键脚本对应

| 治理规则 | 落地脚本 |
|----------|---------|
| H 统一口径 | `cross_words.py`（H 换算）、`unify_heat.py`（跨板块统一）|
| GameLook 禁主页占位 | `daily_refresh.py` 自洽校验 (b) |
| 源覆盖透明 | `daily_refresh.py` 自洽校验 (c) |
| 词云 date 必须当天 | `cross_words.py` 启动检查 |
| 日历名域一致性 | `daily_refresh.py` 自洽校验 (c3) + `GAME_DOMAIN` |
| 禁搜索链接 | `cross_words.py` 安全护栏 + `daily_refresh.py` 自洽校验 (c2) |
| 近 7 天窗口 | `meme_radar.py` 时效红线（14天）+ `daily_refresh.py` 自洽校验 (e) |
